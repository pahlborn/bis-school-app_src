# 3B Big Quest

Learning game for Grade 3B (Bavarian International School), built from the class Toddle content.

Open it here: https://pahlborn.github.io/bis-school-app/

**iPad:** open the link in Safari, tap Share, then *Add to Home Screen*. Stars and progress are saved on the device.
